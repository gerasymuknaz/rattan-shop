# 🪴 ПоліКашпо — Адмін-панель (Flask + SQLite3 + AdminLTE)

Повноцінна серверна адмін-панель для сайту **index.html** на базі **Flask**, **SQLite3** та шаблону **AdminLTE 3 (Bootstrap 4)**.

---

## 🚀 Швидкий запуск

### 1. Запуск сервера
Запустіть файл `run.bat` у папці проєкту або виконайте команду в терміналі:
```bash
python app.py
```

### 2. Посилання у браузері
- **Вітрина магазину (index.html):** [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
- **Панель керування AdminLTE:** [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)

### 3. Доступ до адмінки:
- **Логін:** `admin` *(або `nzrka`)*
- **Пароль:** `admin123` *(або `20112009Gg`)*

---

## 🧭 Відповідність адмінки до секцій index.html

Всі сторінки та поля адмін-панелі прив'язані до конкретних блоків вашого сайту:

| Секція на index.html | Що відображає на сайті | Де налаштовується в адмінці |
| :--- | :--- | :--- |
| **Каталог товарів** (`#catalog`) | Фото, назва, розмір, ціна, стара ціна, бейдж, категорія | **Товари ➔ Картки товарів** (`/admin/products`) |
| **Категорії каталогу** | Кнопки фільтрів («Всі», «Маленькі», «Середні», «Великі», «Набори») | **Товари ➔ Категорії** (`/admin/categories`) |
| **Головний екран Hero** (`.hero`) | Заголовок 1, Заголовок 2, Опис під заголовком | **Налаштування ➔ Головна сторінка** (`/admin/settings`) |
| **Знижковий банер** (`.cta`) | Промокод магазину (`ПОЛІ15`) | **Налаштування ➔ Промокод** (`/admin/settings`) |
| **Контактні дані** (`#contact`) | Телефон, Email, Адреса, Графік роботи майстерні | **Налаштування ➔ Контакти** (`/admin/settings`) |
| **Соціальні мережі** | Посилання на Instagram, Telegram, Facebook | **Налаштування ➔ Соцмережі** (`/admin/settings`) |
| **Відгуки** (`#reviews`) | Відгуки клієнтів, зірки рейтингу, автор, локація | **Відгуки покупців** (`/admin/reviews`) |
| **Кошик та замовлення** (`#orderModal`) | Замовлення, оформлені покупцями на сайті | **Замовлення** (`/admin/orders`) + друк накладної |
| **Форма зв'язку** (`#contactForm`) | Повідомлення від відвідувачів сайту | **Повідомлення** (`/admin/messages`) |
| **Кнопка 🔒 у футері** | Клік веде безпосередньо у нову адмінку AdminLTE | Автоматичний перехід на `/admin` |

## 📁 Структура файлів проєкту

```text
rattan-shop/
├── app.py                     # Головний Flask-додаток (рендеринг index.html, API, адмінка)
├── database.py                # Робота з SQLite3 (структура таблиць, початкові дані)
├── rattan_shop.db             # База даних SQLite3 (автоматично оновлюється)
├── requirements.txt           # Залежності проєкту (Flask, Werkzeug)
├── run.bat                    # Скрипт запуску в 1 клік для Windows
├── style.css                  # Стилі вітрини
├── script.js                  # Клієнтська логіка кошика та відправки замовлень
├── static/
│   ├── css/admin.css          # Стилі для адмінки (прев'ю зображень, плашки)
│   ├── js/admin.js            # Інтерактивне прев'ю фото, обробники
│   └── uploads/               # Папка завантаження фотографій товарів
└── templates/
    ├── index.html             # Шаблон вітрини (серверний Jinja2-рендеринг із SQLite)
    └── admin/
        ├── base.html          # Макет AdminLTE 3 (сайдбар, меню, лічильники)
        ├── login.html         # Авторизація
        ├── dashboard.html     # Зведений дашборд зі статистикою
        ├── orders.html        # Замовлення з чеком/накладною для друку
        ├── messages.html      # Повідомлення з форми «Напишіть нам»
        ├── reviews.html       # Керування відгуками сайту
        ├── categories.html    # Керування категоріями каталогу
        ├── settings.html      # Контакти, тексти сайту та зміна пароля
        └── products/
            ├── index.html     # Таблиця товарів із фільтрами та пошуком
            └── form.html      # Створення/редагування картки товару
```
